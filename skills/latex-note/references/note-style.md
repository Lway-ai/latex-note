# LaTeX 笔记格式约定

以下是默认值，用户指定或既有工程样式优先。中文技术笔记以原生 XeLaTeX 排版为主，不再套用旧 Word 模板或 OMML 检查器。

## 正文与数学

- A4，左右约27 mm、上下25 mm；宋体小四正文，西文Times New Roman，首行缩进2字，约1.4倍行距。
- 使用 `ctexart`、`amsmath`、`unicode-math`；数学字体使用 `latinmodern-math.otf`（Latin Modern Math）。通过文件名加载，避免字体未注册时按显示名称查找失败。中文字体可按平台使用Windows字体或Fandol，不要求安装不存在的字体。
- 行内变量直接写 `$g_m$` 等原生数学；显示公式按正文数学基准字号自然排版，不沿用旧Word固定16 pt。完整数学字族负责根号、分式、运算符及上下标的度量与字形，禁止强制逐字替换Times New Roman。
- 变量斜体；说明性下标如 `\mathrm{in}`、`\mathrm{out}` 正体；函数使用 `\operatorname{Re}`、`\log`、`\exp` 等。正确表达单位、绝对值、复数和向量，保留来源的数学含义。
- 公式自动按节编号，如(4.2a)，正文用 `\label` 和 `\ref` 引用。长公式优先用 `aligned` 或 `split` 合理换行，不通过整体缩小挤进版心。

## 图片、页眉与分页

- 黑体章节标题，宋体正文与题注，页码连续。图号按节自动生成。图片保持纵横比，采用相对路径。
- 图片邻近对应说明；浮动体不要割裂段落与推导。必要时用合理分页或浮动屏障。不要把参考来源最后一两行推到单独一页。
- 曲线图沿用本地MATLAB图表风格；需要重新生成时可用 `scripts/matlab_chart_style.m`，最终嵌入后检查字号与图例可读性。不得仅靠压缩图片来满足页数。
- 电路图符号、同名端、支路标签与电流方向要与正文一致。图中文字并非可编辑TeX数学时，应在交付说明中如实区分。

## 交付与验证

- 源码工程至少有 `main.tex`、所有被引用图像/输入文件、编译说明；如需打包，将 `.tex`、PDF、图片、参考文献与必要构建脚本一起打包，排除历史渲染和临时日志。
- 至少两遍XeLaTeX或等效latexmk构建，交叉引用完成；无编译错误、缺字、未定义引用或公式超宽。环境版本提示不等于编译失败，应保留真实状态。
- 必须检查最终PDF的全部渲染页。编译成功不能证明公式推导、模拟结果或引用真实性。
- 继续已有笔记时，只重跑需要重跑的模拟；排版转换沿用既有数据时明确说明，不虚报为本轮验证。
